# FlashCards

FlashCards is a responsive web application for organizing and practicing flash card decks. Users can browse their decks, open an individual deck to view its cards, and enter Practice Mode to study the cards one at a time.

## Features

- View multiple flash card decks
- Open individual decks and view their cards
- Practice flash cards using an interactive carousel
- Flip cards between questions and answers
- Navigate forward and backward through cards
- Delete decks and individual cards
- Responsive layout for desktop and mobile screens
- Mobile action buttons pinned to the bottom of the screen
- Multiple deck colors
- Box shadows and responsive styling based on the Figma design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- ES Modules
- Responsive Web Design
- BEM naming methodology
- Git and GitHub

## Project Structure

The project is organized into separate HTML, CSS, JavaScript, image, and vendor files.

JavaScript is separated into modules for:

- Deck data and functionality
- Flash card carousel functionality
- Color utilities
- Application routing and rendering

## Responsive Design

The application is designed to work on both desktop and mobile screens.

The mobile version includes:

- Stacked deck cards
- Responsive flash cards
- Pinned New Deck, New Card, and Practice controls
- Mobile-friendly Practice Mode navigation

## Figma

The responsive layouts were implemented based on the provided Flash Card App Figma designs.
